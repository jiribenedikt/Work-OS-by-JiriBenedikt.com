# Tool Conventions

Read when using apps, connectors, files, spreadsheets, or automation tools.

## Files and folders
- Only search within folders mounted to the project. If a file cannot be found, ask.
- Ask before renaming, moving, or deleting the user's files.

## Spreadsheets
Record number, date, and currency formats and any modeling conventions the user requires.

## Documents and slides
- Inspect rendered visual documents before delivering when possible.
Record template, font, and layout preferences here.

## Connectors and automation
Record which connectors and automations are approved, and which actions need confirmation first (for example sending messages).

## Checks before delivering
Record tool-specific checks to run before a deliverable is handed over.

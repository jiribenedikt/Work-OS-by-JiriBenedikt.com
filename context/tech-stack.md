# Tech Stack

Read when a task depends on devices, software, services, integrations, or configuration.

## Devices and operating system
Record the user's operating system and devices, since they affect file paths, shortcuts, and instructions.

## Software and services
Record the main apps, subscriptions, and services in use.

## Integrations and configuration
Record connected accounts, API setups, and configuration details worth remembering. Never store passwords, keys, or tokens.
